# Pixel Pirates

Chrome extension (Manifest V3). Main logic is in `content.js`; the version lives in `manifest.json`.

## Versioning

Any change to the project must bump the patch version in `manifest.json` (e.g. `0.3.0` -> `0.3.1`).

## Commits

Commit messages must follow [Conventional Commits](https://www.conventionalcommits.org/) (e.g. `feat: add better animations`, `fix: correct pirate sprite offset`).
