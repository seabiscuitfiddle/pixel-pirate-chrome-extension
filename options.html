PIXEL PIRATES

How to summon them

Click the toolbar icon (click again to stop) • Alt+Shift+P raid the page • Alt+Shift+O pick one element to plunder • right-click anywhere for the same options.

Raid behaviour

"Only click or press a key" is handy for screen recordings and demos, where the mouse needs to roam. 1 = lazy deckhands, 5 = full mutiny.

Surprise mode (optional)

Needs permission to run on all websites. Leave this off and the extension only touches a page when you invoke it.
Never auto-raid hostnames containing (one per line)
Banks, webmail, Google Docs, .gov and similar sites are always skipped. Manual raids work anywhere.
